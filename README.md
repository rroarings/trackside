# Trackside

Trackside is a modern Formula 1 fan site providing up-to-date stats, schedules, team and driver info, and stories—all in one place. Built for speed, accessibility, and a beautiful experience on any device.

## Features

- 📅 Complete F1 race calendar
- 🏎️ Team and driver stats
- 📰 Blog and stories from the world of Formula 1
- 📊 Standings and results
- ⚡ Fast, responsive, and accessible UI
- 🌙 Light and dark mode support

## Tech Stack

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)
- JavaScript/TypeScript

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start the development server:**
   ```sh
   npm run dev
   ```
   The site will be available at `http://localhost:4321` by default.
3. **Build for production:**
   ```sh
   npm run build
   ```
4. **Preview the production build:**
   ```sh
   npm run preview
   ```

## Project Structure

```
/astro.config.mjs         Astro configuration
/package.json             Project metadata and scripts
/public/                  Static assets (images, fonts, etc.)
/src/
  components/             UI components (Astro)
  content/                Blog posts, drivers, races, etc.
  layouts/                Page layouts
  pages/                  Site pages (routes)
  styles/                 Global styles (Tailwind)
  utils/                  Utility scripts
```
